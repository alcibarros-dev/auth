Um exemplo de uso do auth

Esta aplicação web não tem tela de login: quem cuida do login, do cadastro e da senha é o servidor de autorização (auth). Ao clicar em Entrar, o navegador vai até ele, você entra (ou cria uma conta) e volta para cá com um código, que esta aplicação troca por tokens.

Depois do login, a página /painel mostra, com os seus dados reais, tudo o que o auth emitiu: o que tem dentro de cada token, onde cada coisa fica guardada, o que a API extrai do token e o que o servidor de autorização oferece hoje.
